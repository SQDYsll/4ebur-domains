# 4ebur-domains
Данные этого репозитория предоставлены в целях ознакомления.

В данном репозитории присутствуют следующие сервисы:

PrivatBank

MonoBank

Tik-Tok

YouTube

Discord

X

Facebook

Spotify

ChatGPT

RuTracker

Если у меня что-то перестанет работать и я это замечу, обязательно обновлю список как только замечу проблему.
Я не гарантирую 100% работоспособность, а так-же возможен хлам в виде случайных доменов в списке, в любом случае, я получаю результат в виде работы приложения/ресурса.

Чтобы обуздать силу sorter.py, вам нужно переместить python файл в папку, создать файлы input.txt и output.txt. В input.txt добавить домены, каждый должен начинатся с новой строки. Запустить скрипт. Результат будет находится в output.txt. Внутри файла python есть комментарии которые могут помочь вам понять логику. Соответвенно, нужно заменить в нём что вы хотите добавить до и после домена.
